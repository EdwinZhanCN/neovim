# Neovim (Universal)
Simple neovim setup for C, C++, python

## Download Neovim from 
[official repo](https://github.com/neovim/neovim/blob/master/INSTALL.md)

## Usage:
1. download nvim
2. clone or download my repo
3. put my `nvim directory` under:
**Windows**
`%USERPROFILE%\.config\`
**Mac**
`~/.config/`
**Linux**
`~/.config/`
4. Start your terminal or powershell, type `nvim` , enter.
